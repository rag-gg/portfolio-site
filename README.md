# Anurag Patil — Portfolio

Static developer portfolio with responsive layouts, SVG technology icons, GSAP scroll animations and reduced-motion support.

## GitHub Pages

Publish from the `main` branch and `/docs` folder:

1. Open this repository's **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select **main** and **/docs**, then **Save**.

GitHub Pages will show the published URL when deployment completes. The expected project-site address is `https://rag-gg.github.io/portfolio-site/`.

## Updating the site

Edit the HTML, CSS, JavaScript or assets inside `docs/` and push to `main`. GitHub Pages automatically republishes that folder. No package installation or build command is needed.

The site includes self-hosted fonts, GSAP/ScrollTrigger, Lenis, Lucide interface icons and Simple Icons technology logos. Their licenses and versions are in `docs/assets/`.

The Pearly and Align visuals illustrate project workflows. The fitness visual is a labelled recreation based on project screenshots. The original resume is included unchanged.
